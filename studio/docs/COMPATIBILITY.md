# Compatibility report

Generated by `node studio/tools/gen-docs.mjs` from real runs of the chapter importer against the original game’s source (`saint-marrow/js`, read-only). Nothing in this file is typed in by hand except the headings and the “Formats” section.

## What the importer produces

One Studio project per chapter. **1 map cell = 1 metre**; coordinates are preserved (no re-centring), so a position in the Studio is the same position in the game. Doors, windows, walls, floors, props, lights, items, enemy spawns, triggers, interactions, decals and player spawns become editable objects. Each carries `meta.source` (game, chapter, cell, legend mark) so the origin of every object is traceable.

## Built-in asset library

`studio/assets-builtin/library.json` indexes the assets the original game already ships — 57 models and 54 textures, licence: CC0 1.0 (Poly Haven, https://polyhaven.com). They are referenced by path from `saint-marrow/assets` (read-only); the Studio never copies, replaces or edits them. Each entry records its format and measured bounds.

## Formats

| Direction | Format | Status |
|---|---|---|
| Import models | `.glb`, `.gltf` (+ external buffers/textures), `.obj` (+ `.mtl`), `.fbx` | supported; Draco, Meshopt and KTX2/Basis decoders are vendored. Each file is inspected (triangles, bounds, materials, animations, missing dependencies) before it is added. |
| Import textures | `.png`, `.jpg`, `.jpeg`, `.webp`, `.ktx2` | supported |
| Import audio | `.wav`, `.mp3`, `.ogg` | supported (decoded with Web Audio; the waveform tool reports peaks, clipping and silence) |
| Not imported | `.blend`, `.max`, `.3ds`, `.dae`, `.stl`, `.psd`, `.tga`, `.bmp`, `.gif`, `.mp4`, `.flac`, `.m4a`, archives | refused with a message saying what to convert them to |
| Never imported | `.js`, `.mjs`, `.html`, `.exe`, `.bat`, `.sh` | code is refused as an asset; plugins come in through the Plugins tab and never run until approved |
| Project | `.smproj` (zip bundle: `project.json` + `manifest.json` + assets, SHA-256 verified) and `.json` | versioned (`format` + `version`); migrations run on load; files from a newer Studio are refused with a clear message |
| Export | `.smproj`, story outline `.md`, diagnostics report `.md`, plugin `.smplugin.json` | **there is no export into the playable game** (by design: the playable game is never modified) |

## Original game vs the import — what is verified

Verified by `tests/browser/original-oracle.test.mjs`, which runs the **original game in Chromium** (read-only) and compares:

- **Prop collision boxes**: every explicitly placed prop has a counterpart with the game’s footprint (within 10 cm for fixed props; compared by footprint size for wall-mounted props whose side the game picks at random).
- **Interaction points**: x, y and z of every “use” point the game registers (including the fuse box at y = 2.9 m).
- **Reachability**: every item the Studio reports as unreachable is also not pickable in the original with the game’s own `findInteractable()` from any place its collision lets a player stand; nothing the original can reach is flagged.
- **The chapter 5 gate** is imported open, as the game builds it.

Not verified (and not claimed): the game’s runtime behaviour (AI, scripts, physics feel), visual fidelity of lighting/materials, and anything randomised per session (clutter, wall sides, prop rotations).
