# Sound credits

Every sound effect in `assets/sfx/` is cut from a Freesound recording released under **Creative Commons 0 (CC0 1.0, public domain dedication)**: <http://creativecommons.org/publicdomain/zero/1.0/>. The CC0 license was checked on each sound's own Freesound page. Attribution is not required by CC0; it is listed here as a courtesy and for provenance.

The cuts (start, duration, filters, gain) are defined in `tools/sounds.json` and built with `node tools/assets.mjs sounds`, which downloads the Freesound HQ MP3 previews listed there.
